# 프로젝트 설명 문서

## GPU Skinning

Skeletal mesh 변형을 CPU 전용 계산에서 GPU 기반 처리로 확장

사용자 기능:

- CPU/GPU skinning mode 전환 기능 추가
- `skinmode cpu`, `skinmode gpu` runtime console 전환 기능 추가
- GPU skinning 상태에서도 skeletal mesh 렌더링, shadow, depth, selection 유지
- Editor ID picking이 GPU skinning 결과와 맞도록 수정
- `skinmode status` 기반 현재 skinning mode 확인 기능 추가

Inside:

- CPU skinning 보존 및 GPU skinning 병행 구조 정리
- Bind-pose vertex buffer와 bone matrix structured buffer 기반 GPU vertex shader skinning 추가
- Opaque, depth, shadow, selection mask, ID pick pass의 skeletal resource binding 통일
- Component 단위 `bUseSkinCache` opt-in 정책 정리
- Compute shader 기반 `SkinCache` 구조 도입
- `FVertexSourceBuffer`, `FRWVertexBuffer`, `FSkinCacheManager`, `FSkinCachePass` 기반 deformed vertex cache 구성
- `SkinCacheCS.hlsl`, `EVertexFactoryType::SkinCacheSkeletalMesh` 기반 compute output render path 추가
- C++ vertex layout과 HLSL source layout의 계약 명시 및 static assertion 검증

## Bone Weight Heatmap

Skeletal mesh의 bone influence를 표면 색상으로 확인하는 디버깅/분석용 viewer 기능

사용자 기능:

- 선택 bone 기준 vertex weight heatmap 표시 기능 추가
- Skeletal mesh viewer에서 bone weight 분포 확인 기능 추가
- Viewer show flag 기반 heatmap on/off 기능 추가
- Heatmap opacity 조절 기능 추가
- CPU/GPU skinning mode와 무관한 bone influence 확인 기능 추가

Inside:

- Mesh surface 전용 `MeshOverlayRenderPass` 추가
- 기존 line/debug overlay와 triangle mesh overlay 책임 분리
- `BoneWeightHeatmap.hlsl` shader 추가
- `SkeletalMeshOverlay` vertex factory 추가
- 원본 `BoneIndices`, `BoneWeights` 기반 heatmap 계산 경로 추가
- Skin Cache output과 별개로 원본 skeletal vertex influence를 유지하는 overlay path 구성

- Skeletal mesh preview와 animation playback 분리
- Play, pause, stop, looping, reverse playback, time control 기능 추가
- Animation notify marker 생성/삭제/직렬화 기능 추가
- `.animsm` state machine asset 사용 기능 추가
- State machine graph viewer 추가
- State node와 transition edge 기반 visual editing 기능 추가
- Visible pin 없는 state-to-state direct edge UX 적용
- 양방향 transition overlap 방지용 edge offset 표현 추가
- Animation viewer 검색 기능 추가
- Animation test pawn 기반 locomotion/attack runtime 검증 scene 추가
- Animation notify 기반 attack audio playback 기능 추가

Inside:

- Bone transform track의 position/rotation/scale key sampling 구조 추가
- Shape key animation track의 후속 확장 기반 추가
- Animation sequence asset serialize/load 경로 추가
- Skeleton, skeletal mesh, animation의 독립 asset 구조 정리
- Target skeleton 기반 animation 재사용 구조 정리
- Runtime lazy FBX import 축소 및 명시적 `.bin`, `.anim` asset 중심 load 정책 정리
- `UAnimInstance` 공통 animation runtime 진입점 추가
- `NativeInitializeAnimation()`, `NativeUpdateAnimation()` 사용자 hook 분리
- Internal graph evaluation 단계 분리
- `UAnimSingleNodeInstance`, `FAnimSequencePlayer` 기반 single sequence playback 추가
- Root animation node 개념 도입
- Sequence playback과 state machine playback의 notify dispatch 통합
- `.animsm` asset의 state, transition, entry state, stable id 저장 구조 추가
- State별 animation path, loop, blend time, priority, easing option 저장
- Bool, int, float, vector, trigger parameter declaration 추가
- Parameter store 및 transition condition 평가 기능 추가
- Transition condition type compatibility 검증 추가
- JSON 임시 경로 대체 및 `.animsm` editor/runtime/package asset화
- State node 위치 metadata 저장
- `AAnimTestPawn` 기반 runtime validation path 추가
- Lua binding에서 `AnimInstance`와 `SkeletalMeshComponent` animation 책임 분리

## Reflection

Editor, serialization, Lua binding이 공통 runtime type 정보를 사용할 수 있도록 확장된 reflection 기능군

사용자 기능:

- Details panel animation property section 표시
- Animation sequence asset reference property 표시/편집 기능 추가
- State machine asset reference property 표시/편집 기능 추가
- Array property 기반 editor property 표시 기반 추가
- Lua definition 갱신으로 script에서 신규 animation/reflection API 사용 가능

Inside:

- `UClass` 기반 runtime class metadata 추가
- `UFunction` 기반 function metadata 추가
- `FProperty` 기반 property metadata 추가
- `FReflectionRegistry` 기반 reflection lookup 구조 추가
- Bool, int, float, string/name property 지원
- Object reference property 지원
- Static mesh, skeletal mesh, texture, material, animation sequence, state machine, curve, scene, sound asset reference property 지원
- `TArray` property 연산 지원
- Array resize, remove, element access, serialization 공통 처리 추가
- Reflection 기반 property value get/set helper 추가
- Lua binding 표면 갱신
