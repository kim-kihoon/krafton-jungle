# Monkey Hospital 게임 설명

## 개요

`Hospital`은 반복되는 병원 공간 안에서 이상현상을 찾아내고, 제한된 탄약으로 정답 대상을 맞춰 루프를 끊는 1인칭 호러 게임이다.

플레이어는 병원 복도를 이동하며 문을 열고, 카메라와 권총을 전환해 현재 루프에서 발생한 변화를 확인한다. 이상현상은 평소에는 자연스럽게 숨겨져 있으며, 일부 현상은 사진을 찍었을 때만 드러난다. 플레이어가 정답 이상현상을 맞추면 시간이 멈추고 다음 루프로 넘어갈 준비가 된다.

## 핵심 목표

플레이어의 목표는 제한 시간 안에 현재 루프의 이상현상을 찾아 권총으로 맞추는 것이다.

- 병원 내부를 탐색한다.
- 이전 루프와 다른 점을 찾는다.
- 필요하면 카메라로 사진을 찍어 숨겨진 이상현상을 확인한다.
- 확신이 들면 권총으로 이상현상 대상을 맞춘다.
- 정답을 맞추면 루프가 멈추고, 다음 루프로 진행한다.
- 최종 단계에서는 별도 엔딩 흐름으로 진입한다.

## 기본 조작

| 동작 | 입력 |
| --- | --- |
| 이동 | `W`, `A`, `S`, `D` |
| 문 상호작용 | `E` 액션 |
| 장비 전환 | `Space` |
| 권총 발사 | `LMB` |
| 사진 촬영 | 카메라 장비 상태에서 `LMB` |
| 활성 이상현상 디버그 표시 | `Q` 또는 패드 `L2` |

장비는 권총과 카메라 두 가지 상태를 가진다. `Space`를 누르면 현재 장비가 전환된다.

## 게임 흐름

### 타이틀

게임은 타이틀 화면에서 시작한다. 타이틀 화면에서는 시작, 랭킹, 설정, 크레딧 UI를 사용할 수 있다. 시작 버튼을 누르면 타이틀 연출이 재생되고, 페이드 전환 뒤 플레이어가 병원 내부 조작 상태로 들어간다.

### 루프 시작

게임이 시작되면 `GameManager`가 플레이 상태로 전환되고, 현재 루프의 이상현상을 준비한다. 플레이어는 병원 안을 탐색하며 문을 열고 이동한다.

루프가 시작될 때마다 제한 시간이 초기화되고, 점수와 압박 단계가 현재 상태에 맞게 갱신된다. 일부 점프스케어는 루프 시작 시 활성화될 수 있다.

### 이상현상 탐색

이상현상은 `AnomalyCandidate` 대상 중 하나에 적용된다. 현재 활성 이상현상 대상은 내부적으로 `ActiveAnomalyTarget`으로 관리된다.

이상현상의 예시는 다음과 같다.

- 사진에만 대상이 사라지는 현상
- 사진을 찍으면 화면이 검게 나오는 현상
- 사진 속에서만 다른 유령 액터로 대체되는 현상
- 사진 속에서만 스켈레탈 메시의 뼈가 비틀리는 현상
- 화면 밖에 있을 때만 방향이나 애니메이션이 바뀌는 현상

일부 이상현상은 육안으로 바로 보이지 않고, 카메라 촬영 결과를 통해서만 판별된다.

### 정답 처리

권총으로 현재 활성 이상현상 대상 또는 `ActiveAnomalyTarget` 태그가 붙은 액터를 맞추면 정답으로 처리된다.

정답을 맞춘 직후에는 다음 처리가 일어난다.

- 충돌 위치에 이상현상 히트 파티클을 재생한다.
- 현재 이상현상이 클리어 상태로 기록된다.
- 루프가 정지된다.
- 타이머와 원숭이 루프 진행이 멈춘다.
- 최종 단계라면 엔딩 흐름으로 진입한다.

정답을 맞췄다고 해서 이상현상 효과가 즉시 원복되지는 않는다. 기존 이상현상은 다음 이상현상을 준비하거나 게임을 리셋할 때 정리된다.

### 실패 처리

플레이어는 한 스테이지에서 제한된 탄약을 가진다. 현재 기본 탄약 수는 3발이다.

정답이 아닌 대상을 쏘면 실패로 기록된다. 실패가 누적되면 남은 시간이 빠르게 줄어들고, 조건을 만족하면 게임 오버 흐름으로 진입한다.

게임 오버 시에는 전용 원숭이 연출과 후처리, 사운드가 재생된 뒤 재시작 또는 타이틀 복귀 UI가 표시된다.

## 사진 시스템

카메라 장비 상태에서 `LMB`를 누르면 사진 촬영이 요청된다. 사진 촬영은 현재 뷰포트 렌더 결과를 기반으로 폴라로이드 사진 텍스처를 만든다.

촬영 직전에는 사진 전용 상태 변경이 잠깐 적용된다.

- `PhotoInvisible` 태그 액터는 사진에서 숨겨진다.
- `PhotoBlackoutTarget` 조건을 만족하면 사진 내부 이미지가 검게 처리된다.
- `PhotoGhostReplacementTarget`은 원본 대신 별도 유령 액터가 보이도록 바뀐다.
- `PhotoBoneTwistTarget`은 촬영 순간에만 뼈 회전이 비틀린다.
- 플레이어가 들고 있는 카메라 메시가 사진에 찍히지 않도록 숨겨진다.

촬영 직후에는 임시 변경이 복구된다. 따라서 사진은 이상현상을 판별하기 위한 증거 역할을 하며, 실제 월드 상태를 영구적으로 바꾸지 않는다.

## 루프와 문

병원은 루프 구조로 진행된다. 플레이어가 특정 문과 상호작용하거나 워프 흐름을 통과하면 다음 루프 상태로 넘어갈 수 있다.

문 시스템은 다음 요소를 관리한다.

- 문 열림과 닫힘
- 자동 닫힘
- 출구 문 잠금과 해제
- 루프 시작 문 이벤트
- 플레이어 충돌 보정
- 문 소리 재생과 지연 닫힘 소리

정답을 맞춰 루프가 멈춘 상태에서는 다음 루프를 시작하기 전까지 시간이 흐르지 않는다.

## 점프스케어

점프스케어는 별도 트리거 액터와 매니저로 관리된다. 활성화된 점프스케어 트리거는 플레이어가 충돌 영역에 들어왔을 때 스켈레탈 메시를 이동시키고, 설정된 애니메이션과 사운드를 재생한다.

점프스케어는 한 번 발동한 뒤 같은 스테이지에서 다시 동작하지 않도록 `JumpScareTriggered` 상태를 사용한다.

## UI

게임에서 사용하는 주요 UI는 다음과 같다.

- 타이틀 메뉴
- 랭킹 화면
- 설정과 크레딧 팝업
- 조작 안내
- 문 상호작용 프롬프트
- 타이머
- 조준점
- 카메라 셔터 효과
- 게임 오버 메뉴

리더보드는 클리어 기록을 저장하고 다시 불러올 수 있도록 직렬화 구조를 가진다. 타이틀 화면의 랭킹 메뉴에서 저장된 기록을 확인할 수 있다.

## 승리와 종료

플레이어가 루프를 진행하며 최종 단계의 이상현상을 맞추면 엔딩 흐름으로 진입한다. 클리어 시점에는 플레이 시간, 점수, 클리어 사유가 리더보드 기록으로 저장된다.

게임 오버가 발생하면 재시작하거나 타이틀로 돌아갈 수 있다. 재시작 시에는 플레이어 위치, 문 상태, 장비 상태, UI, 이상현상 상태가 초기화된다.

## 분위기와 플레이 의도

게임은 빠르게 적을 처치하는 슈터보다, 반복되는 공간에서 작은 차이를 관찰하는 호러 탐색에 가깝다.

플레이어는 같은 병원을 반복해서 지나가며 다음 질문을 계속 확인하게 된다.

- 방금 전 루프와 무엇이 달라졌는가?
- 이 변화는 실제 월드에서 보이는가, 사진에서만 드러나는가?
- 지금 쏴도 확실한가?
- 남은 시간과 탄약으로 더 확인할 여유가 있는가?

카메라와 권총의 전환은 이 판단을 강제한다. 카메라는 증거를 확인하는 도구이고, 권총은 결정을 확정하는 도구다.
